# BOSS 直聘海投助手 1.1.9 · Edge 独立扩展

本扩展不需要油猴。安装包请先解压，再在 Microsoft Edge 中加载。

## 安装

1. 在 Edge 地址栏输入 `edge://extensions`。
2. 打开「开发者模式」，点击「加载解压缩的扩展」。
3. 选择当前这个直接包含 `manifest.json` 的文件夹。
4. 停用以前的油猴版助手，刷新 BOSS 页面。
5. 在面板填写并保存配置，点击「开始」才会运行。

不要直接把 ZIP 拖进扩展页。安装完成后保留当前文件夹；移动或删除它会导致扩展不可用。更新文件后，在扩展管理页刷新扩展，再刷新 BOSS 页面。

## 配置

旧油猴版的私有配置无法自动读取，请重新填写规则、AI 接口和密钥；旧版当日额度也不要视为已迁移。

关闭 AI 或没有配置完整接口时可直接使用完整本地规则。必含词支持 MCU/单片机、C++/CPP 等技术词别名；明确的技术培训、非外包等上下文不再误跳过。使用 AI 时，先填写并保存接口，再点击 Edge 工具栏里的本扩展按钮，授权配置中的 AI 域名。每个不同接口域名均需要授权。

AI 按设置顺序依次判断，第一个不可用立即试下一个。全部失败时保留当前岗位，等待一分钟后从第一个开始全部重试，持续循环；可随时暂停、停止或关掉 AI。请求仍受每日额度限制，额度不足时保留岗位等待恢复或调整设置。

开启 AI 后，本地关键词硬过滤仅在离线流程执行。AI 完整阅读个人画像，区分已掌握技能及等级、项目、意向、缺口与未验证能力；实际 MCU/RTOS 工作或可选分支可匹配，纯深入 Linux/PCIe 等工作不能仅因同属嵌入式就放行。“愿意考虑 ECU/AUTOSAR”不等于已熟练，普通入职培训不能豁免必备核心要求。请在画像中写清真实技术水平。

飞控、无人机控制等岗位应按 JD 中的 RTOS、传感器、执行器、底层固件和实时控制职责与 MCU/RTOS 技能及相关项目对照。标题不能保证适合，纯 Linux 或必备的高级算法能力仍需个人画像中的证据。

离线关联只使用当前岗位的实际职责，区分公司介绍、必备核心要求、明确否定和任选条件。

投递或判定不合适后，先切换并确认下一张，再进入批间休息。点击使用标题或主体的实际命中节点，未选中时尝试其他区域，选中后等待正文更新；成功框未关闭、停止、风控或额度已满时不继续推进。旧正文残留时继续等待和重试，提前选中的快照会重新校验。“准备调用”日志可查看本次职位 ID 和送入 AI 的正文，缓存命中另有标注。

招呼语在 BOSS 直聘手机 App 中设置。扩展仅点击 BOSS 官方沟通按钮；识别到“已向BOSS发送消息”或本次按钮变为“继续沟通”时标记绿色“成功”，关闭成功框后再处理下一家。实际内容与发送结果以 BOSS 消息页为准。

卡片在处理期间显示“读取中”“AI 重试中”“判断中”或“投递中”，本次投递结果显示“成功”或“失败”，附具体原因。“AI 通过”说明模型筛选通过；自动投递关闭时的“筛选通过”说明只完成筛选；“已沟通过”说明既有沟通记录。读取未就绪的失败表示还没有得到该岗位的 AI 判断。已点击沟通但没有收到官方成功回执时，标为“失败”并提示到 BOSS 消息页核对；已发起的占额和去重继续保留。最近一笔操作在一分钟内收到同岗位的迟到成功回执时，原卡修正为“成功”并清理成功框，已经停止的任务保持停止。

换岗后原次回执监听永久失效，返回原卡也不会认领其他岗位的弹窗。请求 AI 或保存记录时卡片被替换，原岗位的状态不会写到新卡上。

配置保存在扩展本地存储；AI 请求发送到你配置并授权的服务。浏览器节能、标签页休眠和系统休眠仍可能暂停运行。

工具栏弹窗可显示助手或停止当前页面任务。只打开职位详情或加载扩展不会自动开始投递。

列表采用边处理边补加载：先处理已经出现的新岗位，分屏向下滚动加载；没有新增时向上回滚一段再重新到底，连续检查三轮后才停止。页面高度未变化、卡片被重复利用或混合显示时，仍按岗位身份识别未处理内容。

## 验证

1.1.9 明确过程状态和成功、失败结果，补充飞控实时固件方向与 MCU 背景的关联。回执期间只复核岗位身份，日志和统计刷新跳过冗余扫描；成功框消失后持续确认隐藏状态，页面查询较慢时也完成稳定期。完整画像沿用主备接口，点击“准备调用”日志可核对完整提示词。

完整回归清理测试窗口及回调引用，保留岗位身份、投递次数和 AI 输入检查。具体验证结果见源码包的 VALIDATION.md。验证未向真实招聘方发送消息，实际内容与结果仍以 BOSS 消息页为准。
